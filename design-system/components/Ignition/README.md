The cold open: a dead interface waiting to be switched on, one word in the centre of a slowly turning ring.

Use it once, before any phase exists, because a browser will not play sound or start speech until the page has been clicked. It is the whole screen and the only thing that takes a click until it goes. It is removed by a plain conditional, never by an exit animation: an invisible full-screen button left in the DOM swallows every hit-test on the page.

The consumer provides the start handler. Space and a clap can also fire it.

- Ground: a radial gradient from `ignition-core` at the centre to `bg` at 70%, on `z-ignition`. Colour is `ignition-ink`, which is not a phase token.
- `ignition-ring`: `ignition-ring` wide, 1px `ignition-ink` at 28% with the top edge at 90%, `radius-round`, turning once per `t-ignition-spin` in CSS (never in a motion library: an infinite motion animation keeps the overlay alive).
- `ignition-word`: 15px, 0.52em with a matching `text-indent`, `glow-ignition`; hover raises the glow to 44px at full. `ignition-sub` is 9px, 0.28em, uppercase, at `dim-title`, 12px below.
